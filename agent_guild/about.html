About Subagent Guild

Your central hub for discovering, evaluating, and managing Claude Code subagents from the vibrant open-source community.

Our Mission

The Subagent Guild was created to solve a fundamental challenge in the AI agent ecosystem: discoverability and organization. As the number of Claude Code subagents grows across multiple repositories, developers need a centralized platform to:

  • • Discover agents that match their specific development needs
  • • Compare capabilities and find the best tools for their projects
  • • Access curated collections without manual repository browsing
  • • Stay updated with the latest additions to the agent ecosystem

How It Works

🔄 Automated Discovery

Our system continuously monitors multiple GitHub repositories containing Claude Code subagents, automatically discovering new additions and updates.

🤖 AI-Powered Classification

Each agent is analyzed using Claude AI to extract metadata, classify its purpose, and determine its place in the software development lifecycle.

🔍 Smart Search & Filtering

Advanced search capabilities let you filter by role type, lifecycle phase, technology stack, and more to find exactly what you need.

📦 Easy Distribution

Select multiple agents and download them as organized packages, ready to integrate into your development workflow.
