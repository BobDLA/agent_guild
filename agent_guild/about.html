📖 About Subagent Guild

Learn about our mission to organize and discover Claude Code subagents

Our Mission

The Subagent Guild is a centralized platform for discovering, evaluating, and managing Claude Code subagents from multiple Git repositories. We aim to make it easier for developers to find the right AI development partners for their specific needs.

By aggregating subagents from public repositories, classifying them using Claude API, and providing a comprehensive web interface, we create a thriving ecosystem where developers can discover, evaluate, and utilize specialized AI agents.

Key Features

Agent Discovery

Browse and search through a curated collection of specialized AI agents

Smart Classification

Agents are categorized by lifecycle phase and role type for easy discovery

Side-by-Side Comparison

Compare multiple agents to find the perfect match for your project

Repository Integration

Seamless integration with multiple Git repositories and communities
